# 흑기사의 직장생활 · 팀 프로젝트 발표 자료

AI 영상 콘텐츠 팀 프로젝트 **「흑기사의 직장생활 — 퇴사와 할부 사이」**의 발표 자료와 정리 문서입니다.
Illustrator 일러스트를 After Effects(Duik Angela)로 리깅한 2D 애니메이션에, Codex로 Blender 스크립트를 짜서 만든 3D 오프닝·쿠키 영상을 더한 오피스 블랙코미디입니다.
Claude Code와 함께 기획서를 정리하고 발표 슬라이드를 만들었습니다.
