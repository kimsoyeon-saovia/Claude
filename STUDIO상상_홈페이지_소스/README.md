# STUDIO 상상 · 통합 홈페이지 소스

2차 팀 프로젝트 **STUDIO 상상 통합 홈페이지**의 소스 코드입니다.
가상의 AI 영상 제작사 홈페이지로, 네 명이 네비게이션 메뉴 4개를 한 페이지씩 맡아 Codex · Claude Code로 만들고 하나로 합쳤습니다.

## 여는 방법

`index.html`을 Chrome이나 Edge로 열면 ABOUT US 페이지로 이동합니다. 별도 설치나 빌드는 필요 없습니다.

## 폴더 구성

| 폴더 · 파일 | 메뉴 | 내용 |
|---|---|---|
| `index.html` | — | 시작 페이지 → ABOUT US로 이동 |
| `site-header.js` · `site-header.css` | 공통 | 네 페이지에 같은 헤더 · 푸터 · 메뉴를 넣어 주는 공통 파일 |
| `main/` | ABOUT US | 메인 배너, 파트너 로고 띠, 서비스 4종, 포트폴리오 미리보기, 회사 위치 |
| `ai-video/` | AI VIDEO | 제작 방식 3단계, 제작 과정 4단계, 상담 준비 안내창, 제목 등장 효과 |
| `portfolio/` | PORTFOLIO | 분류 필터, 작업물 카드, 상세창 · 영상 재생창 |
| `contact/` | CONTACT | 개인 · 기업 문의 전환, 견적 자동 계산, 상담 안내창, FAQ |

## 이 저장소에서 뺀 파일 (용량 문제)

GitHub은 한 파일이 100MB를 넘으면 받지 않아서, 아래 파일은 올리지 않았습니다. 그래서 이 저장소만으로는 **PORTFOLIO 페이지가 열리지 않습니다.**

| 파일 | 크기 | 이유 |
|---|---|---|
| `portfolio/index.html` | 약 113MB | 이미지 32장이 코드 안에 직접 들어 있음 |
| `portfolio/videos/` (영상 16개) | 합계 약 1GB | `parents.mp4` 한 개가 약 180MB, 나머지도 대부분 50MB 이상 |

이미지를 별도 파일로 빼고 영상을 압축하면 올릴 수 있습니다.

- 상담 접수와 결제는 실제로 연결되지 않은 시연용 화면입니다.
